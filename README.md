# Pi-Server & REST-API – Lernpfad LF11 (Lehrkraft-Repo)

In 9 Leveln richten die Schüler einen Raspberry Pi als Datenbankserver mit REST-API ein und sprechen ihn am Ende
aus einem selbst geschriebenen Dart-Programm an. Fortsetzung der **Flutter-Einführung**.

**Alles wird getippt:** Die Schüler bekommen keine Projektvorlage. Sie arbeiten mit der Lernpfad-Seite
(eine einzige HTML-Datei, für mebis) und kontrollieren sich über die **Selbstkontrolle** je Level.

- Seite bauen: `python3 tool/seite_bauen.py` → `docs/index.html` (eigenständig, Bilder und Schriften eingebettet)
- Hinweise, Aufbau, Abnahme: siehe `LEHRKRAFT.md`
