# LF11 – Lernpfade

Drei aufeinander aufbauende Lernpfade für LF11. Alles wird selbst getippt, jedes Level hat eine Selbstkontrolle.
Jede Seite ist eine einzige HTML-Datei und lässt sich so auch in mebis hochladen.

| Lernpfad | Seite | Ordner |
|---|---|---|
| 1 · Flutter-Einführung (9 Level, begleitet oder Profi) | https://bnbsinfo.github.io/lf11_lernpfade/flutter/ | `flutter_einfuehrung/` |
| 2 · Pi-Server & REST-API (9 Level) | https://bnbsinfo.github.io/lf11_lernpfade/rest/ | `rest/` |
| 3 · Flutter-Datenbankanbindung | https://bnbsinfo.github.io/lf11_lernpfade/datenbank/ | `flutter_datenbank/` |

Übersicht: https://bnbsinfo.github.io/lf11_lernpfade/

## Für die Lehrkraft
- Hinweise je Lernpfad: `flutter_einfuehrung/LEHRKRAFT.md`, `rest/LEHRKRAFT.md`
- Seite neu bauen und veröffentlichen: `./veroeffentlichen.sh flutter|datenbank|rest|alle` (fragt das Lösungs-Passwort)
- `docs/` ist das, was GitHub Pages zeigt – nicht von Hand bearbeiten.
- Die Musterlösungen auf den Seiten sind verschlüsselt. Im Repo selbst liegen sie lesbar (`loesungen/`), denn das Repo ist öffentlich.
